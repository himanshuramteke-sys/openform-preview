# Openform — design asset library prototype

A static prototype for a community-first design asset library. The visual direction is typography-led, monochrome, and editorial, with a practical searchable resource grid.

## Preview
Once GitHub Pages is enabled for the `main` branch and `/(root)`, the site will be available at:
`https://himanshuramteke-sys.github.io/openform-preview/`

## Files
- `index.html` — homepage
- `library.html` — searchable, filterable sample library
- `styles.css` — responsive styling and monochrome interface
- `app.js` — search, category filters, sorting, theme toggle, detail modal, sample SVG export/copy

## Local use
Open `index.html` in a modern browser. No build step or package manager is required.

## Prototype limitations
This is not yet a production asset platform. The 12 entries are illustrative sample compositions; they are not a vetted catalogue of third-party resources. The download/export actions create original sample SVGs. There is no backend, member submission, moderation, analytics, or licensing-review workflow. Google Fonts are loaded externally and system fallbacks are available.

Before a public launch, replace sample content with real assets, verify supported formats and licences, provide attribution where needed, and implement the contribution/moderation workflow.
